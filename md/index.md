# 水鱼之家 · 在线工具

水鱼之家工具站提供图片处理与开发者常用工具，全部在浏览器本地运行，文件不会上传服务器。

## 图片工具

- [图片格式转换](https://tool.waterfish.ren/Image/ImageConvert)：PNG、JPEG、WebP 等格式互转，支持批量处理。
- [图片压缩](https://tool.waterfish.ren/Image/ImageCompress)：调整质量重新编码，减小图片体积。
- [图片尺寸调整](https://tool.waterfish.ren/Image/ImageResize)：按指定宽高缩放，可锁定宽高比。
- [图片 Base64](https://tool.waterfish.ren/Image/ImageBase64)：图片与 Base64 编码互转。
- [图片旋转翻转](https://tool.waterfish.ren/Image/ImageRotate)：旋转、水平翻转与垂直翻转。
- [图片水印](https://tool.waterfish.ren/Image/ImageWatermark)：批量添加文字水印。

## JSON 工具

- [JSON 格式化](https://tool.waterfish.ren/JSON/JSONFormat)：格式化、压缩和校验 JSON。

## 开发工具

- [时间戳转换](https://tool.waterfish.ren/Dev/TimeConvert)：Unix 时间戳与本地时间、UTC、ISO 双向转换。
- [颜色转换](https://tool.waterfish.ren/Dev/ColorConvert)：HEX、RGB、HSL 转换与颜色预览。
- [密码生成](https://tool.waterfish.ren/Dev/PasswordGenerator)：自定义长度与字符集生成随机密码。
- [URL 编解码](https://tool.waterfish.ren/Dev/UrlCodec)：URL 编码与解码。
- [Base64 编解码](https://tool.waterfish.ren/Dev/TextBase64)：文本与 Base64 互转。
- [哈希计算](https://tool.waterfish.ren/Dev/HashGenerator)：生成 SHA 摘要。
- [UUID 生成](https://tool.waterfish.ren/Dev/UuidGenerator)：批量生成 UUID v4。
- [文本统计](https://tool.waterfish.ren/Dev/TextCounter)：统计字符、汉字、单词与字节数。
